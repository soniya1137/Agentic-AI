# todo-cli

A small to-do list command-line tool written in Python (standard library only).

## Usage

```
python todo.py add Buy milk
python todo.py list
python todo.py list --all
python todo.py done 1
python todo.py delete 1
```

Tasks are saved in `todo.json` next to the script.

## Requirements

Python 3.8 or newer. No extra packages needed.
